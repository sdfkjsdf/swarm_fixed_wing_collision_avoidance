# 문서 안내

현재 코드와 실행 절차는 다음 문서를 기준으로 한다.

- `DEPLOYMENT_SETUP_GUIDE.md`: 환경 구성과 실행
- `PROJECT_FILE_DIAGRAM.md`: production/testing 소스 구조와 의존 방향
- `FILE_FUNCTION_REFERENCE.md`: 현재 파일별 역할
- `FORMATION_MODE_ARCHITECTURE.md`: formation runtime 설계
- `SUBSCRIBER_DATA_FLOW.md`: ROS callback과 RT loop 데이터 흐름
- `TRAJECTORY_PREDICT_HOW_IT_WORKS.md`: 예측 모델과 알려진 한계

`DESIGN_AUDIT_*`, `HANDOFF_*`, `SESSION_TRANSPLANT_*`, `PROPOSAL_*`,
`TASK_*`, `migration_guide_v2.md`는 당시 설계 결정과 인수인계 기록이다. 이 문서의
경로와 명령은 현재 트리와 다를 수 있으므로 실행 절차의 기준으로 사용하지 않는다.
